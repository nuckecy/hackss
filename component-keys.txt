# SDS Component Keys — Extraction Guide
# ======================================
#
# The sds-components.json file uses "YOUR_KEY_HERE" as placeholder keys.
# You need to extract real component keys for figma.importComponentByKeyAsync() to work.
#
# SDS Figma File ID: J0KLPKXiONDRssXD1AX9Oi
# SDS Community URL: https://www.figma.com/community/file/1380235722331273046/simple-design-system
#
# ──────────────────────────────────────
# OPTION A: Figma REST API (Recommended)
# ──────────────────────────────────────
#
# 1. Get a Figma personal access token from: https://www.figma.com/developers/api#access-tokens
#
# 2. Run this command:
#    curl -H "X-Figma-Token: YOUR_FIGMA_TOKEN" \
#      "https://api.figma.com/v1/files/J0KLPKXiONDRssXD1AX9Oi/components"
#
# 3. The response will contain all published components with their `key` field.
#    Each component object has: { key, name, description, ... }
#
# 4. Update sds-components.json: replace each "YOUR_KEY_HERE" with the real key.
#
# ──────────────────────────────────────
# OPTION B: Figma Plugin Helper Script
# ──────────────────────────────────────
#
# 1. Open the SDS file in Figma (duplicate to your drafts first)
# 2. Publish it as a team library
# 3. Create a temporary plugin with this code:
#
#    const components = figma.root.findAllWithCriteria({ types: ['COMPONENT'] })
#    for (const c of components) {
#      console.log(`${c.name}: ${c.key}`)
#    }
#
# 4. Run the plugin and copy the output
# 5. Update sds-components.json with the real keys
#
# ──────────────────────────────────────
# OPTION C: Manual Extraction
# ──────────────────────────────────────
#
# 1. Open the SDS community file in Figma
# 2. Duplicate it to your drafts
# 3. Publish it as a library
# 4. For each component: right-click → "Copy/Paste as" → "Copy link"
# 5. The URL contains the component key
#
# ──────────────────────────────────────
# IMPORTANT NOTES
# ──────────────────────────────────────
#
# - The SDS Figma file MUST be published as a library in your Figma team
#   for importComponentByKeyAsync() to work.
# - Node IDs (e.g., 4185-3778) are NOT component keys — they're internal
#   Figma references for locating components in the file.
# - Component keys are unique strings like "abc123def456..." assigned by Figma
#   when a component is published.
